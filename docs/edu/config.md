
# Configuración de equipos para entorno educativo

Propuesta para la configuración de los equipos GNU/Linux en un entorno educativo.

# Aplicaciones recomendadas

Ofimática

* Evince/Okular
* LibreOffice
* Flameshot
* Firefox
* Chromium
* Dia
* Calculadora

Arte

* Libresprite
* Gimp, Krita
* Audacity
* VLC
* KdenLive
* Inkscape
* Blender
* pitivi

Instalar los codecs
* `sudo zypper install opi`
* `opi codecs`

Desarrollo

* VS Codium
* Helix
